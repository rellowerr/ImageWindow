# ImageWindow

**ImageWindow** — модификация для Geometry Dash (Geode), которая позволяет выводить любое изображение (картинку, мем, референс, шпаргалку маршрута) прямо на экран во время игры в уровнях!

## ✨ Возможности
- **Своя библиотека фото**: импортируйте сколько угодно картинок прямо из игры или закидывайте файлы в папку мода.
- **Интерактивное перемещение (Drag Mode)**: двигайте окно картинки мышкой по экрану прямо в реальном времени!
- **Пресеты позиции**: быстрое выравнивание (Top-Left, Top-Right, Center, Bottom-Right и др.).
- **Настройка внешнего вида**: масштаб (scale), прозрачность (opacity), угол поворота (rotation), зеркальное отражение (Flip X/Y).
- **Стильный HUD**: возможность включить полупрозрачную рамку окна.
- **Умное скрытие**: скрытие при паузе, скрытие при смерти персонажа, режим только для практики.
- **Поддержка редактора**: можно включить отображение фото в редакторе уровней (идеально для артов и трассировки).
- **Быстрый доступ**: удобная кнопка в меню паузы (`PauseLayer`).
