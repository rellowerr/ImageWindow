# ImageWindow (Geometry Dash Mod)

Модификация для Geometry Dash на базе загрузчика **Geode**, которая позволяет загружать любые изображения и отображать их поверх экрана прямо во время игры на уровнях и в редакторе.

---

## 📸 Основные возможности

1. **Библиотека изображений (Галерея)**:
   - Импорт любых изображений (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`) через системный проводник Windows.
   - Быстрый доступ к папке с картинками мода через кнопку **«Папка с фото»** (открывает проводник).
   - Список файлов с предпросмотром миниатюр, разрешением в пикселях и размером файла.
   - Быстрое переключение активного изображения одной кнопкой **«Выбрать»**.
   - Удаление ненужных картинок прямо из меню мода.

2. **Интерактивное перемещение мышью (Drag Mode)**:
   - Нажмите кнопку **«Переместить мышью»**, зажмите картинку и перетащите её в любое удобное место экрана.
   - Отображение точных координат в процентах от экрана в реальном времени.
   - Кнопки **«Сохранить»** и **«Отмена»**.

3. **9 пресетов положения**:
   - Мгновенная привязка:
     - `TL` (Top-Left / Сверху слева)
     - `TC` (Top-Center / Сверху по центру)
     - `TR` (Top-Right / Сверху справа)
     - `CL` (Center-Left / Слева по центру)
     - `C`  (Center / Точно по центру)
     - `CR` (Center-Right / Справа по центру)
     - `BL` (Bottom-Left / Снизу слева)
     - `BC` (Bottom-Center / Снизу по центру)
     - `BR` (Bottom-Right / Снизу справа)

4. **Тонкая настройка внешнего вида**:
   - **Масштаб (Scale)**: слайдер от 10% до 300%.
   - **Прозрачность (Opacity)**: слайдер от 5% до 100%.
   - **Поворот (Rotation)**: слайдер от 0° до 360°.
   - **Рамка HUD**: стильная темная полупрозрачная рамка окна вокруг фото.
   - **Flip X / Flip Y**: зеркальное отражение по горизонтали и вертикали.
   - **Сброс**: возврат всех настроек к начальным значениям.

5. **Гибкие параметры отображения**:
   - **Слой отображения (Z-Order)**:
     - Поверх всего интерфейса (HUD)
     - Под кнопками интерфейса (над блоками)
     - Позади уровня (на заднем плане)
   - **Скрывать при паузе**: автоматическое скрытие при входе в меню паузы.
   - **Скрывать при смерти**: скрытие фото при гибели персонажа.
   - **Только в практике**: фото видно исключительно в режиме Practice Mode.
   - **Показывать в редакторе**: включение отображения в редакторе уровней (для создания пиксель-артов и трассировки).
   - **Горячая клавиша F8**: быстрое включение/выключение отображения прямо во время игры.

6. **Быстрый доступ**:
   - Кнопка вызова настроек в меню паузы (`PauseLayer`).
   - Кнопка в меню паузы редактора (`EditorPauseLayer`).
   - Кнопка в главном меню игры (`MenuLayer`).

## 📦 Как собрать и установить мод

### Способ 1: Локальная сборка через Geode CLI

1. Установите [Geode CLI](https://docs.geode-sdk.org/getting-started/install-cli):
   ```powershell
   winget install GeodeSDK.GeodeCLI
   ```
2. Установите необходимые компоненты (Visual Studio Build Tools с C++20).
3. Настройте SDK:
   ```powershell
   geode sdk install
   ```
4. Соберите мод:
   ```powershell
   geode build
   ```
   Файл мода `low.image_window.geode` появится в папке `build/` или сразу установится в игру командой:
   ```powershell
   geode build --install
   ```

### Способ 2: Автоматическая сборка через GitHub (без установки компилятора)

1. Загрузите этот проект в свой репозиторий на GitHub.
2. Во вкладке **Actions** автоматически запустится рабочий процесс сборки.
3. После завершения скачайте готовый артефакт с файлом `.geode` и поместите его в папку `geode/mods/` вашей Geometry Dash:
   ```text
   C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\geode\mods\
   ```
